# [Frequency of Element](https://www.geeksforgeeks.org/problems/find-the-frequency/1)
## Easy
Given an array arr of positive integers and an integer x. Return the frequency of&nbsp;x in the array.Examples : Input: arr = [1, 1, 1, 1, 1], x = 1
Output: 5
Explanation: Frequency of 1 is 5.Input: arr = [1, 2, 3, 3, 2, 1], x=2
Output: 2
Explanation: Frequency of 2 is 2.
